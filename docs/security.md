# 输入、资源与数值边界

本库针对有限、已按同一采样网格排列的离线数据；不联网、不读写文件、不运行用户脚本。调用方负责访问控制、数据保密、采样时钟和结果解释。

资源限制在分配前检查：轨迹 1..4096 行、1..64 维，有限坐标绝对值 <=1e100；导入矩阵每边 <=4096、总格数 <=1048576。调用方预算只能收紧硬上限。距离、递归预算必须为正。嵌入原始序列 <=262144 个值，嵌入行数仍 <=4096。

目标率选择 max_cells <=262144；窗口与阈值扫描累计格数 <=16777216；阈值列表 1..256 项。滞后范围 -4096..4096。SVG 输出预算 <=65536 格、每格1..32像素、标题 <=512 个 UTF-16 代码单元。CSV／JSON 文本 <=2097152 个 UTF-16 代码单元，JSON 嵌套深度 <=4。它们不是操作系统内存配额，也不提供运行时超时／取消。

Double 有舍入误差；阈值附近数值可能受浮点运算影响。欧氏距离使用缩放平方和；标准化先缩放中心化差值再计算方差。它们减少下溢，不保证次正规数的相对精度。所有比较语义和删失规则在 README 中明确。

SVG 标题视为文本转义，不插入任意 XML 标签、CSS、链接或脚本。CSV 报告字段来自数值及固定列名，不接受公式标题。输入 CSV 不支持引号或嵌入换行。公开可构造的摘要在表格导出前验证；直接使用记录时调用方可显式 `validate`。

遇到错误返回 `Result::Err`，无部分结果；接口 `unwrap` 只适用于已验证输入或示例。不要将大于预算的请求通过提高常量绕过限制。
